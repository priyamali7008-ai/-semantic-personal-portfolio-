# 🌐 Personal Portfolio Website

       Welcome to my personal portfolio website! This project showcases my skills, education, services, projects, and professional profile through a clean, responsive, accessible, and user-friendly multi-page website.

## 👩‍💻 About the Project

This personal portfolio website is designed to provide an overview of my background, technical skills, services, projects, and contact information.

The website is developed using modern frontend technologies with a focus on:

- Responsive design
- Semantic HTML5 structure
- Modern CSS3 layouts
- CSS Grid and Flexbox
- Accessibility
- Mobile-first design
- Clean and simple user interface
- Easy navigation
- Professional presentation

## ✨ Features

- 🏠 **Home Page** – Introduction, profile, and social media links
- 👩‍💻 **About Page** – Information about my background, skills, education, and experience
- 💼 **Services Page** – Overview of my web design, web development, and app development services
- 📁 **Portfolio Page** – Showcase of my projects and work
- 📞 **Contact Page** – Contact information, social links, resume, and contact form
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices
- 🌙 **Dark/Light Mode** – Switch between light and dark themes
- ♿ **Accessibility** – Uses semantic HTML and accessibility-friendly elements
- 🎨 **Modern UI** – Clean layout, typography, cards, images, hover effects, and transitions
- 📐 **CSS Grid** – Used for complex two-dimensional layouts
- ↔️ **Flexbox** – Used for alignment and component layouts
- 💾 **Theme Persistence** – Saves the selected theme using Local Storage
- 📱 **Mobile Navigation** – Responsive navigation menu for smaller screens

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic elements
- **CSS3** – Styling, layouts, animations, variables, Grid, Flexbox, and responsive design
- **JavaScript** – Interactive functionality and theme switching
- **Font Awesome** – Icons
- **Google Fonts** – Typography
- **Local Storage** – Stores the user's selected theme preference

📱 Responsive Design

The website follows a mobile-first responsive architecture to provide a consistent experience across different screen sizes.

The website supports:
💻 Desktop
📟 Tablet
📱 Mobile

CSS media queries are used to adapt layouts, navigation, typography, cards, images, and other components according to the screen size.

🎨 Dark Mode & Light Mode
The portfolio includes a Dark Mode / Light Mode feature.
CSS variables are used to manage the theme colors, while JavaScript controls the theme switching.
The selected theme is stored using Local Storage, allowing the website to remember the user's preference.

Accessibility has been considered throughout the website by using:
